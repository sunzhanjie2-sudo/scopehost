# ScopeHost v0.6.4 使用说明

保留完整的软件目录，包括 `_internal` 文件夹。

v0.6.4 移除自动停止和恢复采集。连接、扫描、刷新、保存、断开和错误处理不会自动执行 RUN / STOP；只有用户点击运行、停止、Single，或在示波器面板上操作，才改变采集状态。

现代 Tek 默认读取全部原始记录，`DATA:RESAMPLE 1`，实际采样点数应与设备存储深度一致。RUN 时每通道通过一次 `WAVFrm?` 读回完整记录，各通道依次读取，不保证来自同一次触发；手动 STOP 或 Single 完成后，按最多 500k 点的连续数据块读取同一停止记录。读取结束和断开不会恢复运行。采集页显示读取进度，未采集到数据的通道会提示先运行或执行 Single。详见「MSO44连接说明.md」。

保存完整 NPZ 前，请手动 STOP 或完成 Single，并等待上位机收到完整停止记录。RUN 状态的实时读回会提示先手动停止，软件不会替你停止或重新触发。保存会核验全部启用通道、每通道真实数组点数、设备存储深度和原生采样间隔。部分记录、抽点预览、设置缺失或不一致会明确拒绝保存，不会插值补足点数；失败不会覆盖已有文件。大型记录在后台压缩保存，界面可继续响应，保存只使用点击时已读回的那一帧。旧版 10k 预览归档无法恢复已遗漏的点，需要重新采集。

v0.6.2 的 MSO44 基础实机修正继续保留，包括水平位置、原生截图临时文件、正常断开及时基/V/div 非预设值准确显示。本台设备可用 `StartMSO44.cmd` 直接连接；其他设备请扫描实际地址。旧版验收使用预览数据，其归档不是完整深存储记录。

v0.6.1 修复 v0.6.0 的 VISA 扫描为空回归。连接窗口显示实际 VISA 后端、USB / 串口数量，支持后端选择和「导出连接诊断」。ASRL 是串口，默认隐藏并禁止当作 USB 示波器连接。换电脑必须有兼容的 VISA / USBTMC 驱动，复制软件不会安装系统驱动；NI-VISA、TekVISA、Keysight VISA 等均可按设备兼容性选用。详见「VISA与USB连接说明.md」。

采集页「帧后延迟」为 100～10000 ms，真实设备默认 1000 ms；一帧完整接收并处理后再等待。v0.6.0～v0.6.2 的 Tek 10k～100k 设备抽点预览已退出现代 Tek 的默认采集流程。

VISA 扫描在后台隔离进程执行，连接状态显示核验进度并支持取消；连接超时不会生成替代波形。完整深记录会增加设备处理和 USB 传输时间，可观察进度并等待本轮完成。硬件采样率保持设备读回值，帧后延迟在本轮耗时之后增加等待。

1. 这台 DS1152E：双击 `StartDS1152E.cmd` 自动连接 USB 设备（序列号 DS1EI182307208）。或双击 `ScopeHost.exe`，点击「连接设备」；默认选择真实 VISA/USB，自动扫描并优先显示 USB 设备。
2. 真实连接显示「真实设备 · DS1152E」，仅显示 CH1、CH2。`StartDemo.cmd` 和「模拟信号演示」会生成四通道测试信号，并醒目标注 SIMULATION。连接失败会报错，不会切换成模拟数据。网口可选 TCP/LAN，通常使用端口 5025。
3. 采集页调节时基、触发源、Auto/Normal、边沿及电平；通道页调节 V/div、偏移和耦合。数字输入后按 Enter 或移开焦点提交；左侧「−」减小、右侧「+」增大，偏移步长随当前刻度变化。正在输入和等待设备执行的数字不会被轮询覆盖，执行后显示设备实际读回值。
4. `Single` 会等待有效触发，完成后冻结所有启用通道。等待中可点击「强制触发」或「停止」。
5. 分析页可选择跨帧平均、移动平均、A+B/A−B 数学运算。FFT 按钮打开独立频谱，点击测量表通道行选择分析源。
6. 开启「游标」后可选择时间、电压或同时显示。垂直线 A/B 读取时间、Δt、1/Δt，以及当前通道或全部启用通道在 A/B 处的电压和 ΔV；超出采样范围标注「超出记录范围」。水平线 C/D 按所选通道刻度读取电压和 ΔV，堆叠时位于对应通道分区。总览和 ZOOM 中的光标同步。「保留参考」以虚线叠加当前波形。
7. 「保存 / 导出」提供原始 NPZ、原始/分析 CSV、单通道 CSV、FFT/测量 CSV 和 LTSpice 文件。「保存软件截图」保存整个软件窗口，包括波形、设置面板、光标、测量表和状态栏。
8. 点击「ZOOM 放大」显示总览与局部窗口。总览中的蓝框可拖动移动，拖动左右边界可改变范围，也可在框外拖选新的区间。倍率上限随真实记录点数增加，最小选区为两个采样间隔；支持输入中心时间及本地电压放大。「复位」恢复 4 倍、当前视图中心。
9. 局部窗口的滚轮调节 ZOOM 倍率，拖动平移局部窗口，双击复位。总览开启 ZOOM 时，Alt+拖动可平移总览。游标和参考波形在两窗口同步；下方测量表始终测量整帧。
10. 点击「通道堆叠」，各启用通道按上下分区显示，共用同一时间轴；每个分区保留对应 V/div 和偏移。可与 ZOOM、FFT 同时使用，拖动视图之间的分隔条可调整高度。
11. 「保存 / 导出 → ZOOM 区间 · CSV」导出选区内已有的真实采样点。NPZ 归档保存并恢复 ZOOM、堆叠和光标选项。
12. 波形下方显示各通道实际的硬件带宽限制，如 20 MHz 或「关闭（全带宽）」。旧归档未记录带宽或适配器未提供该参数时显示「未知」。该数值来自设备设置，与上位机本地移动平均分别处理。

快捷键：空格运行/停止；Ctrl+S 保存原始归档；Ctrl+O 打开归档；Ctrl+Shift+S 保存整个软件窗口截图。

NPZ 归档保存每个实际原始采样码、电压数组、采样间隔、通道量程和触发设置，可离线打开并重新分析；还记录实际点数、设备深度和完整性来源。旧归档缺少完整性证据时标记为未知。跨帧平均适用于重复且对齐的波形；Single 绕过跨帧平均。归档不包含平均历史。

现代 Tek 在 RUN 时依次读取各通道完整记录，不自动停止；需要保留同一次采集时，手动 STOP 或使用 Single。已停止记录读取期间若检测到重新运行或采集记录变化，本轮不会发布为完整停止记录。其他厂商按各自已适配协议读取。测量精度受量化精度、采样间隔和可见周期数影响。硬件完整带宽和采样率不等于上位机波形刷新率。

ZOOM 和堆叠仅改变本地显示，保留原始采样，不下发时基、电压或运行控制命令。ZOOM 按时间范围计算局部原始索引；总览中的极值绘图只压缩显示，不压缩原始数组。控制区显示选区内实际点数，局部放大不会增加采样点。数据周期不足时频率/周期显示「—」。

DS1152E（固件 00.04.00.00.01）已通过真实 USB 验证：CH1 校准方波约 0～3 V、1 kHz；CH2 悬空时只有毫伏级底噪。软件不对底噪显示周期/频率。真实测试覆盖时基、刻度、偏移、DC/AC、边沿/模式、运行/停止、Single、强制触发和归档。600 点覆盖 12 个水平格，软件据此换算时间；电压采用 (125-code)*scale/25-offset。量化造成几十毫伏的峰值差异属于当前量程的采样分辨率。

设备采样率与传输到上位机的点数/刷新率分别标注；实际刷新速度由 USB 通信及设置查询耗时决定，以界面帧率为准。现代 Tek 已实现完整深记录分块读取；其他适配器没有获得完整记录时不能保存为完整 NPZ，DS1000E 的 600 点屏幕波形不能冒充深存储。Tektronix MSO44B 和 DS1000Z 仍需各自真机验证。暂不支持脉宽/逻辑/总线触发、串行协议解码和 XY。

v0.6.4 的 MSO44 只读验收已通过：CH1 为 500 万点、2 ms/div、250 MSa/s。手动 STOP 后完整读取约 2.3 秒，NPZ 回读全部原始码值和电压逐点一致；用户手动 RUN 后整包读取约 1.5 秒，设备保持运行。两次日志均无采集状态写入，事件队列为空。当前验收脚本为 `tests/validate_manual_acquisition.py`，报告位于 `artifacts/mso44_v0.6.4/`。历史 v0.6.3 四通道完整读取与深 ZOOM 验收仍保留；其脚本会控制采集状态，不用于当前只读验证。

DS1000E 无原生屏幕图像回传时，设备截图使用真实采样数据重建，并标注来源。部分 DS1000E 固件关闭通道后须在设备前面板重新开启。

## 横河 DLM3000

支持 DLM3022/3032/3052（两通道）、DLM3024/3034/3054（四通道）。选择「TCP / LAN」及「Yokogawa 横河 (DLM3000 系列)」，填写设备 IP，端口 **10002**；设备通信接口选择 Ethernet / Socket。

连续显示时在采集页「设备记录长度」选择 1.25k 或 12.5k。长记录用 Stop / Single，本版完整读取上限 200 万点/通道；可选 125k 或 1.25M。各通道可设置 AC/DC/DC50，显示实际带宽。菜单「设备屏幕截图」直接读取原生 PNG，不用 U 盘。

CH4 在逻辑模式下不作为模拟通道绘制。当前支持模拟电压通道、普通 Edge；电流探头、增强/串行/组合触发尚未适配。横河适配已完成协议和界面验证，尚未经真机验证。详细连接与限制见同目录 `DLM3000连接说明.md`。
