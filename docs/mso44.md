# MSO44 / MSO44B 完整记录与通信说明（v0.6.4）

本次使用 USB 连接的 **MSO44（C049800，固件 1.40.3.236）** 调试，协议核对依据本地 `docs/mso456_prog.pdf`（泰克 4/5/6 系列编程手册）。现代 4/5/6 系列默认走完整记录读取；MSO44B 和其他系列仍需各自真机验证。

v0.6.4 修正 v0.6.3 每轮读取自动停止再恢复运行的行为。连接、扫描、刷新、保存、截图、断开、取消和异常处理均不自动执行 RUN / STOP；运行、停止和 Single 由用户点击软件按钮或操作示波器面板决定。NPZ 继续保留与设备存储深度一致的真实样本；ZOOM 使用原始样本重新绘制选区。

## 连接

1. 保留软件整个目录，运行 `ScopeHost.exe`，点击「连接设备」。
2. USB 选择 VISA / USB-TMC，扫描后选择设备资源，适配器可用「自动识别」或「Tektronix (MSO44 / MSO44B / 4-5-6 系列)」。USB 需要本机可用的 VISA / USBTMC 驱动。
3. 扫描在独立进程中执行，最多等待 8 秒。扫描中可以填写资源地址、切换 LAN 或取消；扫描关闭不会影响其他会话的 VISA 资源管理器。
4. 点击「连接」后状态栏显示打开接口、身份、通道及时基/触发核验进度。连接总等待 15 秒后请求取消，单次通信有 5 秒驱动超时及进程层保护。可随时点击「取消连接」。连接失败不会进入模拟器。
5. LAN 当前使用原始 SCPI Socket。只有仪器开放该 Socket 接口时才能连接，不能将 VXI-11 / HiSLIP 地址当成原始 TCP 端口。VISA 资源支持通过 VISA 驱动访问相应 LAN 接口。
6. 软件当前适配模拟通道的边沿触发及 Sample / HiRes / Average 的 Y 格式；本次实机使用 Sample。数字通道、包络、增强触发需要另行适配。完整读取核验 `DATA:SOURCE:AVAILABLE?`，已开启但尚无采集数据的通道会明确提示先运行或完成 Single，不会用其他通道或生成数据代替。
7. 这台 MSO44 可双击 `StartMSO44.cmd` 连接；另一台设备应从连接窗口扫描选择其地址。

## 完整记录、刷新与点数

采集页新增「上位机刷新 / 通信负载」：

| 设置/读数 | 意义 |
|---|---|
| 帧后延迟 | 100～10000 ms；真实设备默认 1000 ms。接收并处理完一帧后再等待，不包含本轮通信/处理耗时。控制命令可立即打断等待 |
| Tek 读取方式 | 默认完整记录，`DATA:RESAMPLE 1`；RUN 每通道整包读取，STOP 每块最多 500k 点连续读取 |
| 设备记录长度 | 本轮设备读回的真实存储深度；不会为了刷新速度自动降低深度或硬件采样率 |
| 本帧点数 | 只有全部启用通道完整读完并核验后才更新本帧；每通道点数等于设备深度 |
| 读取进度 | 当前通道已收到点数、该通道记录点数，以及所有通道已读/总点数；按实际接收计数 |
| 通信耗时、实际帧率 | 本轮设备传输/查询/本地基础测量耗时，以及实际显示帧率；帧率还受 GUI 分析绘图耗时影响 |

例如，四通道每通道 1000 万点、每点 2 字节，一帧原始采样码约 80 MB，另有前导、设置查询及协议开销；本地电压数组还需要内存。实际 USB 速度受仪器、驱动、接口和设备负载影响，不能仅根据仪器的 GS/s 采样率判断。完整读取允许较慢刷新，不通过抽点降低保存的数据量。

RUN 时，每通道用一次 `WAVFrm?` 响应取得前导和完整原始二进制数据，不把运行期间的多个数据块拼成一条波形。每通道实际点数必须等于设备深度，换算参数、字节数和单位均须有效。各通道依次读取，可能来自不同触发；界面明确标记为 RUN 实时读回，不声明为同一次多通道采集。整包查询按原始数据量延长通信超时，界面继续响应。

用户手动 STOP 或 Single 完成后，读取本轮通道、时基、采样率和触发设置，顺序传输各通道的连续数据块。每块检查实际点数、字节数、换算参数、触发参考点和时间轴连续性；读取前后检查设备深度、运行状态和采集计数。检测到用户重新运行、采集计数变化或数据块不一致时，拒绝发布该帧。不插值、不复制尾部、不补零，也不重新停止设备。读取结束、正常取消或失败都不会重新运行；Single 等待期间不会为了读取而取消触发。

GUI 同时最多等待一帧，处理结束后才继续采集，避免 FFT/ZOOM 较慢时连续堆积波形。

设备控制命令和截图在当前整帧读取结束后执行，深记录时提交设置会有等待，随后显示实际读回值。帧后延迟会在本轮耗时之后增加等待；若测量允许，可自行减少启用通道数或在设备上选择较浅记录。软件不会自动减少原始点数。

正常断开先完成正在进行的当前请求，再停止后续请求，避免中断二进制读取后留下未读 USB 数据。断开不改变示波器采集状态。等待期间界面继续响应；驱动真正挂起时才使用进程取消保护。

## NPZ 保存与 ZOOM

保存完整 NPZ 前，用户应手动 STOP 或完成 Single，并等待上位机收到完整停止记录。RUN 实时读回会提示先手动停止，保存操作不向示波器发送 RUN / STOP，不重新触发，也不另外采集。

NPZ 保存已读回的真实采样码、电压数组、时间轴和本轮设备设置，点数元数据来自数组实际长度。保存前核验每个启用通道已返回、每通道实际点数等于设备深度，以及 `XINCR × 设备采样率 ≈ 1`。明确标记为 RUN 实时读回、抽点预览、部分记录、缺少必要设置或帧设置不匹配时拒绝保存完整归档。记录完整点数与采集稳定性分别写入元数据。失败不覆盖已有文件；大型记录在后台压缩，保存快照属于点击时已经收到的那一帧。

加载 NPZ 会核验所声明点数和实际数组一致，并保留原始读取来源。旧版归档没有完整性证据时显示未知；其中 10k 点不能恢复成 1000 万点，插值也不能补回被抽掉的窄脉冲。需要完整细节时重新采集并保存。

总览按像素保留原始样本极值，仅减少绘图顶点，不改变采样数组。ZOOM 每次按时间范围重新计算局部原始索引，放大后使用该区间内的真实点；最小选区为两个采样间隔，倍率上限随完整记录点数增加。局部点数和游标电压来自同一原始记录。启用本地滤波或平均时，分析视图显示相应处理结果，NPZ 仍保存独立的原始设备数据。

## 修正的协议问题

- 4 系列通道显示查询/设置改为 `DISPLAY:GLOBAL:CHn:STATE`，替换不适用的 `CHn:DISPLAY`。
- 边沿触发电平按实际源查询/设置 `TRIGGER:A:LEVEL:CHn`。
- 初始化关闭响应头、启用完整关键字；读波形前导时暂时开启响应头，读二进制前恢复关闭。解析同时兼容位置字段及命名字段。
- 不再自动把前导点数当成下一帧传输上限。每帧重新读取换算参数；缺少缩放、字节序、点数不一致或未适配编码时拒绝显示，不使用默认缩放。
- 泰克传输错误直接报告，不追加不适用的 `SYST:ERR?` 查询。
- USB 使用 EOM，VISA LAN 二进制查询临时关闭文本终止符，保留数据内部的 0x0A/0x0D。
- 正确读取水平位置：延迟关闭时将 `HORIZONTAL:POSITION` 的百分比换算为时间，延迟开启时使用 `HORIZONTAL:DELAY:TIME`；水平格数来自设备。
- 时基和 V/div 不在标准预设档时显示实际设备读回值，例如 4 ms/div，而不是选择相邻的 5 ms/div；轮询更新不会下发设置命令。
- 原生截图使用唯一临时文件名，保存后等待 `*OPC?`，再读取并验证 PNG，最后删除本次临时文件。避免删除不存在的文件造成事件错误，也避免覆盖设备内已有同名图片；这台 MSO44 已实际返回 1920×1080 PNG。
