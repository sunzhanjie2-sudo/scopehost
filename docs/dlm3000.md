# 横河 DLM3000 连接与支持范围（ScopeHost v0.5.0）

适配型号：DLM3022、DLM3032、DLM3052（2 个模拟通道），DLM3024、DLM3034、DLM3054（4 个模拟通道）。按 `*IDN?` 自动识别，或在连接窗口选择「Yokogawa 横河 (DLM3000 系列)」。DLM3000HD、DLM4000、DLM5000 使用各自手册，未包含在本适配器中。

## 连接

推荐网口连接：

1. 在示波器上配置 IP，使设备与电脑处于可互通的网络。
2. 在设备通信设置中选择 Ethernet / Socket 接口。
3. 上位机选择「TCP / LAN（真实设备）」及横河 DLM3000 适配器，填写设备 IP；端口自动切换为 **10002**。
4. 点击连接，确认设备型号与实际模拟通道数。

该 Socket 接口直接收发 LF 终止的命令。软件不使用横河另一个通信接口的登录握手，也不将端口当成 5025。

USB 仅在所装驱动将设备暴露为 VISA 可访问的 USBTMC 资源时使用「VISA / USB-TMC」。横河 TMCTL 驱动路径尚未接入；如果 VISA 扫描没有该设备，请使用上述网口连接。不要把“支持 USB 指令”理解为任意驱动都能由 PyVISA 打开。

## 已实现

| 功能 | DLM3000 路径 |
|---|---|
| 运行、停止 | `:STARt`、`:STOP`，状态使用 `:STATus:CONDition?` 的 RUN 位 |
| Single | `:SSTart? 0` 立即返回，后台等待完成，不阻塞强制触发与停止 |
| 强制触发、自动设置 | `:TRIGger:FORCe`、`:ASETup:EXECute` |
| 时基与记录长度 | `:TIMebase:TDIV`、`:ACQuire:RLENgth`，显示设备实际读回值 |
| 通道 | `:CHANnel<n>:DISPlay / VDIV / OFFSet / COUPling`；AC、DC、DC50 |
| 边沿触发 | 模拟通道源、电平、上升/下降/双边沿；Auto、Auto Level、Normal、Single |
| 实际带宽限制 | `:CHANnel<n>:BWIDth?`，显示全带宽或设备返回的频率 |
| 连续多通道波形 | `:WAVeform:ALL:SEND? 0`，同一数据块中的通道共享采集计数 |
| 停止/Single 后波形 | `:WAVeform:SEND?`，WORD 小端数据分块读取 |
| 设备原生截图 | `:IMAGe:FORMat PNG`、`:IMAGe:SEND?`；保存后恢复原图片格式，无需 U 盘 |
| 本地分析与导出 | 复用 ZOOM、堆叠、双向光标、FFT、数学运算、CSV、NPZ 归档和整窗截图 |

WORD 电压按设备返回的 `RANGe`、`OFFSet` 换算；时间按实际采样率和触发点计算。设备打开 Offset Cancel 时补回物理输入偏移；独立垂直 Position 用于绘图，不改写原始采样。DC50 与垂直 Position 会保存到归档中。

## 当前限制

- 连续路径按手册支持最多 **12.5k 点/记录**。软件要求传回点数与记录长度一致，避免猜测抽取比例。可在「采集 → 设备记录长度」选择 1.25k 或 12.5k；长记录使用 Stop / Single。
- 本版停止/Single 读取支持完整记录至 **200 万点/通道**，每次传输最多 10 万点。超过此范围会明确报错；不会截断后冒充完整记录。提供 125k 和 1.25M 记录长度选项。
- 连续路径不支持 Roll、Single 正在等待触发、连续统计测量等手册列出的不支持状态；错误时保留上一帧并提示。
- 本版处理模拟电压通道。CH4 切换为逻辑输入时不作为模拟 CH4 绘制；不读取 8 位逻辑波形。电流探头会明确提示未适配，避免将 A 标成 V。
- 当前控制的是模拟通道边沿触发。设备使用增强/串行/组合触发或非模拟通道触发源时，请在面板改为模拟通道 Edge；不会将这些触发读成普通边沿。上位机修改边沿源、边沿或电平时会切换为普通 Edge。
- 本适配按官方手册实现，已通过协议、Socket 会话和 GUI 测试，**尚未经过 DLM3000 真机验证**。
